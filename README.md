# Hi, I'm Chine 👋

I'm a Staff Software Engineer with six-plus years of building software, most of it in Rails APIs that have to stay fast under heavy traffic. I started out in defect management: confirming a requirement was really broken, weighing severity, and working with developers and testers until the fix actually held. I still build with that end in mind.

I came into engineering through Flatiron School, and most of what's public here dates back to those days. I'm modernizing it with Claude Code, so you can follow the upgrades as they land.

## How I work

I plan my work in the open. Each piece starts as a GitHub issue written as a user story with testable acceptance criteria, then gets grouped into a milestone or project so the order and dependencies are clear. Changes go through PRs that explain what changed and why, with tests and CI on every one.

For an example, see the [Move to Vercel milestone](https://github.com/canikwe/Portfolio/milestone/1) for my portfolio site.
